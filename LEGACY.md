# IB Heros - Project Legacy & Knowledge Base

This project evolved from the `apex-tuition` workspace. This document summarizes the core features and technical decisions immigrated from that context.

## 🌟 Evolution
- **Phase 1**: Initial premium tutoring clone (`apex-tuition`).
- **Phase 2**: Rebrand to `ib-heros` with Firebase integration.
- **Phase 3**: Enterprise extensions (CMS, AI Generation, Twilio Notifications).

## 🛠️ Core Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Vanilla CSS Modules
- **Backend**: Firebase (Firestore, Storage, Auth)
- **AI**: Gemini (Content Generation)
- **Notifications**: Twilio (WhatsApp/SMS)
- **Email**: Nodemailer

## 🚀 Key Features
- **Video CMS**: Dual-language video support with "Used" status tracking.
- **AI Integration**: Automatic generation of XHS/TikTok descriptions and hashtags.
- **Tutor Application**: Complex multi-file upload form.
- **NextAuth.js**: Secure login system for dashboard access.
- **Multilingual**: Native `[lang]` routing with Chinese (`zh`) default.
